Isolation Policy v– By RahmatSobrian, mhmrdd

Zygisk port of the Isolation-Policy LSPosed module - blocks isolated / app-zygote service processes for the apps you choose, no Xposed framework required.

This module is provided as-is, without warranty. Denying isolated services for an app may break features that rely on them (WebView sandboxing, some media/DRM codecs, etc.) - if something stops working after enabling a deny, disable it for that app first.
